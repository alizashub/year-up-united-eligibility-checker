# Year Up United Eligibility Checker 📝

A small Python program to help users check if they meet the eligibility criteria for **Year Up United**.  

This project was created as a mini capstone to practice Python basics and apply what I learned during the **Year Up United pre-work phase**.

---

## Features

- ✅ **Age verification** (18–29)  
- ✅ **Work authorization** or DACA status check  
- ✅ **High school diploma / GED** requirement  
- ✅ **College degree restriction**  
- ✅ **Income eligibility** check  
- ✅ **Full-time availability** check  
- ✅ **Commuting distance** to program locations  

---

## How It Works

1. The program asks a series of **questions** about:
   - Age  
   - Education  
   - Work authorization  
   - Income  
   - Availability  
   - Location  
2. Based on your answers, it will tell you if you **meet the eligibility criteria**.  
3. **Error messages** guide users if an answer is invalid.  

---

## How to Run

1. Open the code in **Python** (or run it in [Google Colab](https://colab.research.google.com/drive/1K1ObNUqmbGRse8n-SpY9w32y2AMOom3K?usp=sharing)).  
2. Run the script.  
3. Follow the prompts and answer the questions.
